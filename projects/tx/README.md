# /projects/tx

The Texas project audit: 21 announced ERCOT-bound data center projects, scored on public
evidence.

The underlying data, evidence files, and analysis live in the
[assayenergy/gridscore](https://github.com/assayenergy/gridscore) repo — this folder links to it
rather than copying it, so the source stays the single copy of record. The scored rows are
mirrored into [/ledger/ledger.csv](../../ledger/ledger.csv).

Writeup: [The Texas Governor Ordered a Data Center Audit. I Already Started One by Hand](https://assayenergy.substack.com/p/the-texas-governor-ordered-a-data)
